Campaign checklist

Domain: Detected after login

1. Campaign

Create the base campaign. In this step only the campaign name and type are required.
When realtime transcription is enabled, a transcription service is required. Events transcription can be enabled separately.
Only NCC users with Administrator or Supervisor profiles are listed.
Supervisors load after sign in.

2. Phone routing

For inbound campaigns select an unused NCC number. For outbound campaigns enter the caller ID that will be patched into the campaign.
Create one or more queues. The first queue marked for in-hours routing is used in the workflow.
No queues added yet.

3. Workflow

This creates a workflow and later attaches it to the campaign. The workflow will include the out-of-hours routing condition.

4. Business hours

Define the schedule and business event. The workflow condition will use this business event name.

5. Messages

The out-of-hours message creates a prompt and adds it to the OUT OF HOURS state in the workflow. The in-hours message is captured in the log for now.

6. Dispositions

Create as many dispositions as needed. Each disposition has its own name, one optional action, optional workitem types, and optional flags.
No dispositions added yet.

7. Review and create

Review the values, then create the campaign, phone routing, workflow, business hours and dispositions in NCC.
